# Typed compiler options

The Go compiler stores option values in a typed `CompilerOptions` struct. The C# port previously read most options through a string-keyed `JsonElement` dictionary during program construction and checking. A managed Satori CPU profile with tiered compilation disabled showed repeated option lookups among the checker costs. An earlier differential counter recorded about 40,000 `module` queries and tens of thousands of `strict`, `noImplicitAny`, `allowUnreachableCode`, and `verbatimModuleSyntax` queries for one 5,000-declaration request.

`generate-options.mjs` now derives a typed C# projection from the Go `CompilerOptions` fields and the pinned option schema. It emits the 131 Go fields, the schema-only `plugins` option, and the matching enum values. Boolean options retain three states; path mappings retain declaration order. Setting or merging an option updates its typed value, while raw JSON remains available to config parsing, diagnostics that need the original value, and serialization. Compiler, checker, binder, and resolver paths now read typed members. Derived target, module, module-resolution, and module-detection decisions use those values in one place.

The first focused module cache and typed-boolean controls reduced the five small NativeAOT Satori workload medians by about 4–6%; the original library-heavy workloads were roughly flat. Those controls preceded the complete Go-derived option model. A final NativeAOT publish for the complete model was deferred at the user's request until the remaining performance work is complete. No faster-than-Go claim follows from the controls.

Normal Release validation for the complete typed model passed 13,446 semantic configurations in each checker mode with complete diagnostic records and unchanged output hash `8390e6e546cf407bd5030dfabecd2983bd7aee283ae8d0a0678963646c6b31a4`. All 31 checker API families passed 1,649,908 comparisons with zero candidate failures and four existing Go query failures. All 74 safety suites, 6,778 metadata cases, 86 host assertions, and the focused module naming and package suites passed. The solution built with zero warnings and errors; regenerated options passed `generate-options.mjs --check`. The [validation summary](../csharp/compatibility/evidence/phase4-typed-options-validation.json) records hashes and scope.
