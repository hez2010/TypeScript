# Development environment

The default compiler is C# on every target in [the platform matrix](../csharp/distribution/platforms.mjs). Install Node 24 and a .NET 11 SDK, then follow [CONTRIBUTING.md](../CONTRIBUTING.md). NativeAOT publishing needs the native toolchain for the selected RID. The former Go-only container configuration is preserved in [the oracle archive](../csharp/oracle/build/devcontainer.json).
